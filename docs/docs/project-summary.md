# Project Summary

## Objective
To design and implement a dual-axis solar tracking system capable of automatically aligning a solar panel toward maximum sunlight intensity using LDR sensors and servo motors.

## Key Concepts
- Embedded Systems
- Sensor Interfacing
- Servo Motor Control
- Renewable Energy

## Outcome
The system successfully demonstrated automatic solar panel movement based on real-time light intensity detection.

## Academic Context
Developed as a 3rd semester hardware mini-project.
